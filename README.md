# ☁️ 구름 점프 — 딸과 함께 만드는 모바일 플랫폼 게임

별을 모으며 깃발까지 달려가는 점프 게임이에요. 폰 브라우저에서 바로 플레이할 수 있고,
홈 화면에 앱처럼 설치할 수도 있어요.

---

## 1. 지금 바로 해보기

- **컴퓨터에서:** `index.html` 파일을 브라우저(크롬, 사파리 등)로 열면 끝이에요.
- **폰에서:** 아래 "폰에서 플레이 / 설치하기"를 참고하세요.

조작:
- ← → : 좌우 이동 (폰은 화면 아래 버튼)
- ↑ / 스페이스바 / 점프 버튼 : 점프
- 몬스터는 **위에서 밟으면** 물리쳐요. 옆에서 부딪히면 목숨이 줄어요.

---

## 2. 딸이 직접 바꿔보기 (제일 재미있는 부분!)

`index.html` 파일을 메모장이나 코드 편집기로 열면, 맨 위에 무대(레벨) 그림이 있어요.
**글자만 바꾸면 무대가 바뀌어요.**

```
P = 시작 위치        G = 도착 깃발
# = 땅 / 발판         C = 별(점수)      E = 몬스터
(빈칸) = 아무것도 없음
```

예를 들어 이렇게 한 줄을 그리면:

```
"   C C C          "
"  #######    E    "
" P            G   "
"##################"
```

→ 별 3개가 발판 위에 있고, 몬스터 한 마리가 있고, 오른쪽 끝에 깃발이 있는 무대가 돼요.

숫자를 바꿔서 느낌을 바꿀 수도 있어요 (`index.html` 안 "쉽게 바꿀 수 있는 값들"):
- `JUMP_VELOCITY` : 점프 높이
- `MOVE_SPEED` : 달리는 속도
- `GRAVITY` : 떨어지는 빠르기
- `START_LIVES` : 목숨 개수

> 💡 팁: 무대를 새로 만들고 싶으면 `LEVELS` 목록에 `[ ... ]` 무대를 하나 더 추가하면 돼요.

---

## 3. 폰에서 플레이 / 설치하기

### 가장 쉬운 방법 — 홈 화면에 추가
1. 폰 브라우저에서 게임 주소를 열어요.
2. **아이폰(사파리):** 공유 버튼 → "홈 화면에 추가"
   **안드로이드(크롬):** 메뉴(⋮) → "홈 화면에 추가" 또는 "앱 설치"
3. 홈 화면에 아이콘이 생기고, 누르면 앱처럼 전체 화면으로 실행돼요.

### 인터넷 없이도 실행되게 (PWA 정식 설치)
`manifest.webmanifest`, `sw.js`, `icon.svg` 파일이 함께 있으면, 한 번 열어둔 뒤에는
인터넷이 없어도 게임이 실행돼요. 이렇게 하려면 파일들을 **https 주소로** 올려두어야 해요
(예: GitHub Pages 같은 무료 호스팅). 준비되면 도와드릴게요.
